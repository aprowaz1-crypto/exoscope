# ExoScope

**Браузерний конвеєр для пошуку екзопланет у зоряних кадрах — транзитним методом і методом прямого зображення.**

ExoScope — це open-source вебзастосунок, який працює повністю у браузері: жоден кадр не завантажується на сервер. Він приймає FITS-зображення, FITS-куби `NAXIS=3` та звичайні PNG/JPEG/WEBP, виконує наукову обробку й дозволяє експортувати результати у CSV, JSON, Markdown і PNG.

> ⚠️ ExoScope — дослідницький та освітній інструмент. Автоматично знайдені кандидати **не є відкриттям екзопланети** і потребують незалежного підтвердження, спектроскопії та перевірки на інструментальні артефакти.

## Можливості

### Транзитна фотометрія
- Читання FITS `BITPIX` 8/16/32/−32/−64, `BSCALE`/`BZERO`, `GCOUNT`/`PCOUNT`, кубів `NAXIS=3`.
- Автоматичний пошук зірок: локальна карта фону, адаптивний поріг, звʼязні компоненти, субпіксельні центроїди, FWHM, елонгація, насичення.
- Вирівнювання кадрів за подібнісним перетворенням (зсув + поворот + масштаб) із робастним зіставленням зір.
- Субпіксельна апертурна фотометрія з кільцем неба, фотонним шумом, шумом зчитування та шумом неба.
- Ансамбль зірок порівняння, відсів змінних, сигма-кліпінг, детрендинг за часом/FWHM/небом/airmass/центроїдом, бінінг.
- BLS-пошук періоду у Web Worker із прогресом; спектр потужності, найкращі піки, SDE.
- Трапецієподібна модель транзиту `P, T₀, depth, T₁₄, T₁₂`; похибки з чисельного гессіана; SNRt, χ²/dof, RMS, події.
- Веттинг: odd–even, вторинний мінімум, зсув центроїда, червоний шум, форма, насичення, блендинг.
- Фазова крива, експорт кривої світла та звіту.

### Пряме зображення (ADI/RDI)
- Автоматичний пошук центральної зорі та субпіксельне вирівнювання кадрів.
- Медіанний PSF-референс; віднімання PSF; режими ADI, RDI та ручних кутів.
- Кути `PARANG` із FITS-заголовків або ручний початковий кут і крок.
- Радіальна MAD-оцінка шуму, карта SNR, локальні максимуми вище порогу.
- Кандидати з SNR, контрастом, `Δmag`, відстанню в пікселях і кутових секундах, позиційним кутом.
- Криві граничного контрасту 1σ та 5σ.
- Експорт зображень PNG, кандидатів і кривої контрастності CSV, звіту Markdown/JSON.

### Інтерфейс
- Українська мова за замовчуванням та англійський переклад (перемикач UA/EN).
- Локальна обробка, прогресивні індикатори, адаптивний дизайн.
- Синтетичні демо-набори для транзиту та ADI — без потреби мати файли під рукою.

## Швидкий старт

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev
```

Відкрийте `http://localhost:5173`.

Збірка для продакшену:

```bash
npm run build
npm run preview
```

`npm run build` створює статичний сайт у `dist/` — його можна розмістити на GitHub Pages, Netlify, Cloudflare Pages або будь-якому статичному хостингу.

### Тести

```bash
npm test
```

Тести перевіряють FITS-парсер, BLS-пошук і фіт транзиту, а також обертання зображень і відновлення синтетичного компаньйона в ADI.

## Як користуватися

### Транзит
1. Відкрийте **Транзити** та завантажте серію кадрів або натисніть **Демо**.
2. Перевірте часову шкалу; за потреби задайте початковий JD і крок.
3. Натисніть **Знайти зорі**, виберіть цільову зорю на зображенні або зі списку.
4. Запустіть **фотометрію**, налаштуйте детрендинг і бінінг.
5. Запустіть **BLS**, виберіть пік і перегляньте параметри та веттинг.
6. Експортуйте CSV, PNG, JSON або Markdown-звіт.

### Пряме зображення
1. Відкрийте **Пряме зображення** та завантажте серію кадрів або натисніть **Демо**.
2. Перевірте центр зорі та джерело кутів (`PARANG`, ручні кути або RDI).
3. Задайте піксельну шкалу, кількість кадрів, межі пошуку та поріг SNR.
4. Запустіть **ADI/RDI**.
5. Перегляньте комбіноване зображення, карту SNR, кандидатів і криву контрастності.
6. Експортуйте звіт, таблиці та PNG.

## Підтримувані дані

| Формат | Підтримка |
|---|---|
| FITS-зображення (`NAXIS=2`) | ✅ 8/16/32/−32/−64-bit, `BSCALE`/`BZERO` |
| FITS-куб (`NAXIS=3`) | ✅ кожна площина стає кадром |
| PNG / JPEG / WEBP / BMP / TIFF | ✅ через Canvas |
| FITS-таблиці, `fpack`, gzip | ❌ не підтримуються |

Часові заголовки: `BJD_TDB`, `BJD`, `HJD`, `JD`, `MJD`, `DATE-OBS`. Для `DATE-OBS` додається половина експозиції. Якщо часу немає, використовується заданий початковий JD і крок.

Обмеження памʼяті: приблизно 60 млн пікселів на набір; великі кадри автоматично бінінгуються до 1536 px за найбільшою стороною.

## Наукові обмеження

- Апертурна фотометрія погано працює для насичених зірок, сильного блендингу та змінної прозорості.
- BLS чутливий до червоного шуму; SDE — статистика пошуку, а не ймовірність відкриття.
- ADI потребує достатнього обертання поля (бажано > 10°). Малі кути перетворюють метод на RDI.
- Спекли, дифракційні піки та похибки кутів можуть давати хибні кандидати.
- Результати не є сертифікованим аналізом. Для публікації потрібні незалежні дані, спектроскопія та перевірка.

Детальніше про алгоритми: [`docs/ALGORITHMS.md`](docs/ALGORITHMS.md).

## Технології

- React 19 + TypeScript.
- esbuild для збірки та dev-сервера.

## Деплой на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте код.
2. У **Settings → Pages** виберіть **GitHub Actions** як джерело.
3. Запуште у `main` — workflow `.github/workflows/pages.yml` збере сайт і опублікує його.

Усі шляхи в застосунку відносні, тому він коректно працює у підкаталозі `https://<user>.github.io/<repo>/`.

## English summary

ExoScope is a serverless, browser-based exoplanet-hunting workbench. It processes FITS images/cubes and standard raster images with:

- **Transit photometry:** star detection, similarity alignment, subpixel aperture photometry, ensemble differential light curves, detrending, BLS period search in a Web Worker, trapezoid transit fitting with uncertainties, and false-positive vetting.
- **Direct imaging:** ADI/RDI PSF subtraction, PARANG/manual field rotation, SNR maps, companion candidates and 1σ/5σ contrast curves.

Everything runs locally; no data leaves the browser. Results are research candidates, not confirmed discoveries. Built with React, TypeScript and esbuild; deployable as a static site to GitHub Pages.

```bash
npm install
npm run dev
npm test
npm run build
```
